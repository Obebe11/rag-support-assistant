# Returns Policy

Version 1.3. Effective March 1, 2025. Superseded by version 2.0 on September 1, 2026.

This policy explains when and how you can return items bought from Northline Office Equipment, and how refunds are calculated.

## Return window

You can return most items within 45 days of the delivery date. The delivery date is the date shown in the carrier's tracking record.

## Return authorization

- Every return needs a return merchandise authorization (RMA) number.
- Request an RMA number by email at returns@northline.example.com. Include the order number, the item and the reason for the return.
- We issue RMA numbers within 2 business days.
- An RMA number is valid for 10 days from the date we issue it. Ship the return within that period.
- Write the RMA number on the outside of the box. We refuse packages that arrive without a valid RMA number.

## Item condition and refund amount

| Condition of the returned item | Refund |
| --- | --- |
| Unopened, in the original sealed packaging | 100% of the item price |
| Opened, in like-new condition with all accessories, manuals and packaging | Item price less a 20% restocking fee |
| Defective, damaged in transit or shipped in error | 100% of the item price plus the original shipping charge |
| Used, damaged by the customer or missing parts | Not eligible for return |

Original shipping charges are not refunded unless the return is caused by a defect, transit damage or our error.

## Return shipping

- For a change-of-mind return, you pay the return shipping. Use a service with tracking.
- For defective items, items damaged in transit and items shipped in error, we email a prepaid return label.

## Items that cannot be returned

- Consumables such as toner, laminating pouches, labels and shredder oil, once the package has been opened.
- Special-order items.
- Items sold as clearance or final sale.
- Items returned after the 45-day return window.

## Refunds

- We issue the refund to the original payment method within 10 business days after the return arrives at our returns center.
- For orders paid on a Net 30 credit account, we apply a credit memo to the account instead.

## Exchanges

We do not process direct exchanges. To exchange an item, return it under this policy and place a new order for the item you want.

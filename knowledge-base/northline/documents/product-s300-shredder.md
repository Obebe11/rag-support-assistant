# Northline S-300 Cross-Cut Shredder

Product sheet. Version 1.1. Effective February 1, 2026.

SKU: NL-S300. List price: $279.00.

## Overview

The S-300 is a cross-cut shredder for shared office use. It cuts paper into small particles suitable for confidential business documents and stops automatically when the bin is full or the motor needs to cool down.

## Specifications

| Specification | Value |
| --- | --- |
| Cut type | Cross-cut |
| Particle size | 5/32 x 1-9/16 in (4 x 40 mm) |
| Security level | P-4 |
| Sheet capacity | 18 sheets per pass (20 lb paper) |
| Shredding speed | 9 feet per minute |
| Feed opening width | 9.1 in |
| Bin capacity | 8 gallons, about 600 shredded sheets |
| Continuous run time | 20 minutes, followed by a 40-minute cool-down |
| Dimensions (W x D x H) | 14.5 x 10.6 x 23.2 in |
| Weight | 31 lb |
| Shipping weight | 36 lb |
| Power | 120 V, 60 Hz |

## What it can shred

- Paper, including sheets with staples and small paper clips
- Credit cards, fed one at a time

The S-300 is not rated for CDs, DVDs, laminated sheets, adhesive labels or cardboard. Damage caused by shredding these materials is not covered by the warranty.

## Operating features

- Automatic start and stop when paper enters the feed opening
- Automatic reverse when a jam is detected
- Safety sensor that stops the cutters when a hand touches the feed opening
- Bin-full and overheat indicators
- Pull-out bin and casters

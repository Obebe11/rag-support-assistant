# Northline LP-420 Thermal Label Printer

Product sheet. Version 1.1. Effective March 1, 2026.

SKU: NL-LP420. List price: $219.00.

## Overview

The LP-420 is a direct thermal label printer for shipping labels, barcodes and product labels on label stock up to 4.25 inches wide. It prints without ink, toner or ribbon.

## Specifications

| Specification | Value |
| --- | --- |
| Print technology | Direct thermal |
| Print resolution | 203 dpi |
| Print speed | Up to 6 inches per second |
| Maximum print width | 4.09 in (104 mm) |
| Label width | 1 in to 4.25 in |
| Label supply | Rolls with a 1-inch core and an outer diameter up to 5 in, or fanfold stacks through the rear slot |
| Label detection | Automatic gap sensor calibration |
| Label removal | Tear bar; no cutter |
| Interfaces | USB 2.0 and Ethernet |
| Supported operating systems | Windows 10, Windows 11, and macOS 12 or later |
| Dimensions (W x D x H) | 8.5 x 7.3 x 6.9 in |
| Weight | 4.2 lb |
| Shipping weight | 6 lb |
| Power | External adapter, 120 V input |

The LP-420 does not have Wi-Fi or Bluetooth. To share it across an office, connect it to the network by Ethernet.

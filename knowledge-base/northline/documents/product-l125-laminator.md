# Northline L-125 Thermal Laminator

Product sheet. Version 1.0. Effective February 1, 2026.

SKU: NL-L125. List price: $149.00.

## Overview

The L-125 is a pouch laminator for signs, ID cards, menus and reference sheets up to 12.5 inches wide. It has four heated rollers and a cold setting for pressure-sensitive pouches.

## Specifications

| Specification | Value |
| --- | --- |
| Lamination type | Thermal pouch, with a cold setting |
| Maximum document width | 12.5 in |
| Pouch thickness | 3 mil, 5 mil, 7 mil and 10 mil |
| Warm-up time | 4 minutes |
| Lamination speed | Up to 24 inches per minute |
| Rollers | 4 heated rollers |
| Automatic shutoff | After 60 minutes without use |
| Jam release | Manual release lever |
| Dimensions (W x D x H) | 19.3 x 7.1 x 4.3 in |
| Weight | 9.5 lb |
| Shipping weight | 12 lb |
| Power | 120 V, 60 Hz |
